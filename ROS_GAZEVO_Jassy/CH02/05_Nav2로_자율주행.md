# 05 Nav2로 자율주행 실습하기

> 여기서는 로봇의 Navigation 기능을 수행하는 Nav2에 대해 다룹니다.

## 05_1 Nav2 개요

Nav2는 ROS2에서 내비게이션 기능을 제공하는 대표적인 패키지입니다. 내비게이션을 수행하려면 먼저 로봇 위치 추정(Robot Position Estimate)이 필요합니다. 로봇이 어디에 있는지 알아야 경로(Path)를 계획할 수 있기 때문입니다. 이 위치 정보는 SLAM을 통해 제공됩니다.

또 하나 필요한 요소는 **장애물 인식(Obstacle Awareness)**입니다. 경로를 만들 때 장애물을 피해야 하기 때문입니다. 장애물 정보를 얻는 방법은 크게 두 가지가 있습니다.

1. **SLAM으로 생성한 Static Map** — 기존에 존재하는 벽이나 고정된 구조물
2. **실시간 Lidar 데이터** — 움직이는 사람, 새로 등장한 장애물 등 즉각 감지해야 하는 대상

Nav2는 이 두 가지 정보를 활용하여 /costmap 토픽을 발행합니다.

![costmap 개념](../img/image211.bmp)

costmap은 각 셀(cell)에 비용(cost)을 할당하는데, 장애물 주변은 높은 cost, 안전한 공간은 낮은 cost가 부여됩니다. cost는 단순히 0과 1의 이진 값이 아니라, 장애물에서 멀어질수록 연속적으로(cost gradient) 낮아지는 형태를 갖습니다.

![경로 계획](../img/image212.bmp)

Nav2는 이러한 costmap을 기반으로 가장 효율적이고 안전한 경로를 판단하여, 초기 위치(initial pose)에서 목표 위치(goal pose)까지의 path를 생성합니다.

## 05_2 nav2_bringup으로 자율주행하기

여기서는 이전에 생성한 맵을 이용하여 자율주행을 해 봅니다.

1. 네 개의 명령 창을 띄운 후, 차례대로 명령을 수행합니다.

```
① ros2 launch myrosbot_one robot_bringup.launch.py
② ros2 launch nav2_bringup bringup_launch.py map:=$HOME/maps/map.yaml params_file:=/root/myros_sketch/nav2_params.yaml use_sim_time:=True
③ rviz2 -d /root/myros_sketch/nav2_default_view.rviz \
 --ros-args -p use_sim_time:=true
④ ros2 run twist_stamper twist_stamper \
  --ros-args \
  -r cmd_vel_in:=/cmd_vel \
  -r cmd_vel_out:=/diff_drive_controller/cmd_vel \
  -p frame_id:=base_link \
  -p use_sim_time:=true
```

### mission 파일 준비하기

3. waypoint별로 수행할 mission을 작성합니다.

**my_waypoints_missions.yaml**

```yaml

  waypoint1:
```

### mission 수행 노드 작성하기

4. waypoint별로 mission을 수행하는 노드를 작성합니다.

**my_waypoints_patrol.py**

```python
import yaml
import rclpy

from rclpy.node import Node
from rclpy.action import ActionClient
from nav2_msgs.action import NavigateToPose

class MyWaypointNode(Node):
	def __init__(self):
		super().__init__("my_waypoint_node")

		# 1. waypoint 파일 읽기
		with open("my_waypoints.yaml") as f:
			waypoint_config = yaml.safe_load(f)

		self.waypoints = waypoint_config["waypoints"]

		# 2. mission 파일 읽기
		with open("my_waypoints_missions.yaml") as f:
			mission_config = yaml.safe_load(f)

		self.missions = mission_config["missions"]

		# 3. Nav2 Action Client
		self.nav_client = ActionClient(
			self,
			NavigateToPose,
			"/navigate_to_pose"
		)

	def run(self):
		
		self.nav_client.wait_for_server()

		for name, waypoint in self.waypoints.items():

			self.get_logger().info(
				f"Navigate to {name}"
			)

			# -------------------------
			# NavigateToPose Goal
			# -------------------------

			goal = NavigateToPose.Goal()

			goal.pose.header.frame_id = "map"
			goal.pose.header.stamp = self.get_clock().now().to_msg()

			goal.pose.pose.position.x = float(waypoint["pose"][0])
			goal.pose.pose.position.y = float(waypoint["pose"][1])
			goal.pose.pose.position.z = float(waypoint["pose"][2])

			goal.pose.pose.orientation.x = float(waypoint["orientation"][0])
			goal.pose.pose.orientation.y = float(waypoint["orientation"][1])
			goal.pose.pose.orientation.z = float(waypoint["orientation"][2])
			goal.pose.pose.orientation.w = float(waypoint["orientation"][3])

			# -------------------------
			# Navigation
			# -------------------------

			send_goal_future = self.nav_client.send_goal_async(goal)

			rclpy.spin_until_future_complete(
				self,
				send_goal_future
			)

			goal_handle = send_goal_future.result()

			if not goal_handle.accepted:
				self.get_logger().error(
					f"Goal rejected: {name}"
				)
				return

			result_future = goal_handle.get_result_async()

			rclpy.spin_until_future_complete(
				self,
				result_future
			)

			# -------------------------
			# Mission
			# -------------------------

			mission = self.missions.get(name)

			if mission is None:
				continue

			task = mission["task"]

			if task == "photo":
				self.take_photo()

			elif task == "wait":
				duration = float(mission["duration"])
				self.wait(duration)

	def take_photo(self):
		self.get_logger().info("Take photo")

		# TODO:
		# camera 처리

	def wait(self, duration):
		self.get_logger().info(
			f"Wait {duration} seconds"
		)

		# TODO:
		# 실제 대기 구현


def main(args=None):

	rclpy.init(args=args)
	node = MyWaypointNode()
	node.run()
	node.destroy_node()
	rclpy.shutdown()

if __name__ == "__main__":
	main()
```

> take_photo()와 wait()의 실제 수행 동작을 구현해야 합니다. 여기서는 구체적인 구현을 생략합니다.
